# Bike Rental Demand Prediction and Analysis Using Python

## Project Overview
This project focuses on analysing and predicting bike rental demand using Python and Machine Learning. It explores how factors such as time, season, temperature, weather conditions and working days influence bike rental demand.

## Objectives
- Analyse bike rental patterns using Exploratory Data Analysis.
- Clean and preprocess the dataset.
- Perform feature extraction and feature engineering.
- Build and compare four Machine Learning regression models.
- Identify the best-performing model using evaluation metrics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
1. Linear Regression
2. K-Nearest Neighbors Regression
3. Decision Tree Regression
4. Random Forest Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Dataset
The project uses the Bike Sharing Demand dataset from Kaggle.

Dataset: https://www.kaggle.com/competitions/bike-sharing-demand

Download the dataset and place `train.csv` in the same folder as the Python file before running the program.

## How to Run

1. Install Python.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

3. Download the Kaggle dataset.
4. Place `train.csv` alongside the Python file.
5. Run the Python program.

## Project Outcome
The project compares four regression models and identifies the best-performing model based on RMSE.
